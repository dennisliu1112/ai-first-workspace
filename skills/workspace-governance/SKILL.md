## 1. Naming Convention / 命名鐵律
- **Lowercase `kebab-case` Only**: All newly created directories and cross-project paths MUST use lowercase English letters and hyphens (e.g., `media-studio`, `ai-models`, `ep01-intro`).
- **Zero Spaces**: Spaces and special characters are strictly prohibited in directory names to guarantee zero escaping failures across `zsh`, `bash`, `pwsh`, Docker volume mounts, and Agent tool calls.
- 所有新建目錄與跨專案引用路徑一律採用**英文小寫 + 連字號（`kebab-case`）**，嚴禁空白字元。

## 3. Legacy Directory Auditing & Zero-Downtime Migration SOP / 舊資料盤點與無痛搬家流程

When the user asks to audit, clean up, or refactor their home directory or legacy workspaces, **NEVER move or delete any files before the user reviews the Dry-Run plan**. Follow these 4 steps:

### Step 1: Run Real Token & Disk Audit (`scripts/audit-workspace.py`) / 執行實測盤點腳本
Never invent magic numbers. Run the read-only auditor script (from the local repo `./scripts/audit-workspace.py` or the global skill hub `~/agent-hub/skills/workspace-governance/scripts/audit-workspace.py`) to measure real context token overhead and disk bloat:
```bash
python3 ~/agent-hub/skills/workspace-governance/scripts/audit-workspace.py --root ~/ --out-html ./dist/.cache/dry-run-report.html
```
1. **Real AI Context Token Formula / 真實 Token 精算公式**:
   - Scans auto-loaded AI files (`CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, `.cursorrules`, `.windsurfrules`, `.clinerules`, `SKILL.md`, `MEMORY.md`, `.github/copilot-instructions.md`, `.agents/**/*.md`, `.claude/**/*.md`, `.cursor/rules/*.mdc`).
   - Formula: `Tokens = (ASCII_chars * 0.25) + (Non_ASCII_chars * 1.3) + (Top_Level_Items * 6)`.
   - Reports an itemized token bill per file.
2. **Real Reclaimable Disk Space / 真實可回收空間**:
   - Measures actual byte sizes of `node_modules`, `.venv`, `venv`, `__pycache__`, `target` (Rust), `.gradle`, `.ruff_cache`, `.turbo`, `coverage`, and `dist/.cache`.
3. **Smart Container Unrolling & Content-Based Heuristics / 智慧容器展開與內容特徵識別**:
   - Automatically unrolls generic parent containers (`workspace`, `dev`, `repos`, `code`, or multi-project parents) and classifies folders using internal file signatures (`.obsidian`, model weights, pure docs, media outputs).

### Step 2: Present Refactoring Matrix & Bilingual Interactive Dry-Run HTML / 產出拆解對照表與雙語互動模擬器
1. Present the **Before ➡️ After Refactoring Table** in the user's language (English or `zh-TW`).
2. Present the generated `dry-run-report.html` (which includes a top-right **`繁中 | EN`** toggle and **`macOS / Linux | Windows`** command switch) so the user can inspect every folder's target path, token bill, and symlink commands with 100% confidence.

### Step 3: "Move Physical Folder + Leave Symlink/Junction Behind" / 搬實體 + 原地留軟連結（不斷鏈遷移）
Once approved by the user, always leave a link at the legacy path so hardcoded scripts and IDE shortcuts never break:
- **macOS / Linux**:
  ```bash
  mkdir -p "$(dirname "<new_kebab_path>")"
  mv "<legacy_path>" "<new_kebab_path>"
  ln -sfn "<new_kebab_path>" "<legacy_path>"
  ```
- **Windows (PowerShell — Admin-Free Directory Junction)**:
  ```powershell
  New-Item -ItemType Directory -Force -Path (Split-Path -Parent "<new_kebab_path>") | Out-Null
  Move-Item -LiteralPath "<legacy_path>" -Destination "<new_kebab_path>"
  New-Item -ItemType Junction -Force -Path "<legacy_path>" -Target "<new_kebab_path>" | Out-Null
  ```

### Step 4: Archive Dehydration & TTL Cache Pruning / 封存區脫水與快取清理
- List all rebuildable dependency folders (`node_modules`, `.venv`, `venv`, `__pycache__`) inside `~/archives/` and delete only after user confirmation.

```text
~/ (or %USERPROFILE%\)
├── 📚 knowledge/study/ml-notes/          # [SSOT Knowledge Vault - Read-Only]
├── 🧠 ai-models/tts/custom-voice/        # [SSOT Model Weights - Config Ref]

└── 🚀 projects/media-studio/
    ├── tools/                            # Core engines (voice-kit / anim-kit, pure code in Git)
    └── episodes/ep01-eval-metrics/       # ★ Lightweight Task Workspace opened in Agent (CWD)

        ├── knowledge/                    # 🔗 Symlink/Junction -> ~/knowledge/study/ml-notes
        ├── AGENTS.md                     # 🛡️ Declares external links read-only; write only locally
        ├── prompt.md / script.md         # 📝 State 1: Recipe & script (Git tracked)
        ├── scenes.json                   # 📝 State 1: Storyboard JSON (Git tracked)
        └── dist/.cache/                  # 🗑️ State 2: Transitional cache (Auto-purge / 7-day TTL)
```

- **macOS / Linux**:

## 5. Three-State Output Control / 三態輸出與過渡半成品磁碟控制

1. **State 1 (Source & Recipe / 配方與源碼)**: Only text scripts, configs, and prompts (`script.md`, `scenes.json`) are tracked in Git.
2. **State 2 (Transitional Artifacts / 中間過渡半成品)**:
   - Small temp files (e.g., TTS audio slices) go to system temp (`/tmp/` or `$env:TEMP\`).
   - Resumable render caches (e.g., PNG sequences) go to `./dist/.cache/` (Git-ignored) with **Auto-Cleanup on Success** or **7-Day TTL Pruning**.
3. **State 3 (Final Deliverables / 最終成品)**: Published to `~/outputs/` upon verification, followed by local cache cleanup.

## 6. Anti-Dump Rule: Conversational Sprawl vs. Spatial Routing / 對話可以發散，目錄必須收斂（防就地傾倒鐵律）

In the AI collaboration era, humans naturally brainstorm and spawn side-quests within a single chat window ("Hey, also build me a quick preview button", "Summarize this PDF for later", "Test this TTS model"). An ungoverned Agent blindly dumps all of these into the Current Working Directory (CWD), turning every repo into a junkyard.

在與 AI 協作時，人類習慣在同一個對話視窗裡發散思考（「順便幫我做個 IDE 預覽鈕」、「幫我把這份資料整理成筆記」、「順手寫個小工具測一下」）。若沒有目錄治理，AI 會把所有支線產物全部「就地傾倒（CWD Dumping）」在當前專案裡，不出三天專案就長滿雜草。

**Mandatory Spatial Routing Table / 跨專案空間路由契約（當對話產生支線需求時，Agent 必須自動分流）**:

| When the user asks mid-conversation... / 當對話中途長出以下支線需求時... | ❌ Ungoverned Agent (CWD Dump) | ✅ Governed AI-First Routing (正確自動分流位置) |
| :--- | :--- | :--- |
| **"Make a global UI button / Sidecar / Skill"**<br/>「順便幫我做個全域 UI 小工具或通用技能」 | Dumps `plugin.json` & `sidecars/` inside current repo | Route directly to `~/agent-hub/` or `~/.gemini/config/`<br/>直接寫入全域中樞或系統設定，**當前 Repo 零污染** |
| **"Save this research / study note for later"**<br/>「幫我把這段研究或筆記存起來以後用」 | Creates random `notes.md` in code repo root | Route to `~/knowledge/<domain>/<topic>.md`<br/>自動投遞至純文字知識庫，供未來 RAG 檢索 |
| **"Let's build a quick side-project / utility"**<br/>「我們順手寫個獨立的小工具 / Side-project」 | Mixes unrelated scripts into current repo | Route to `~/projects/<domain>/<new-tool>/` or `~/agent-lab/`<br/>主動在外部建立獨立專案目錄，不與當前專案混放 |
| **"Audit my machine / draft a personal plan"**<br/>「幫我掃描電腦或寫一份個人重構計畫」 | Leaves `.local/` or personal reports in public repo | Route to `~/agent-lab/workspaces/<task>/`<br/>存放於個人實驗沙盒，讓公開 Git 儲存庫 (Repo) 保持 100% 純淨 |
